📋 設定步驟

  1. 開啟你的 Google Sheet，點選上方選單「擴充功能」→「Apps Script」
  2. 刪除預設程式碼，將 gas/Code.gs 的內容全部貼上
  3. 在 CONFIG 中填入你的 Google Sheet ID（網址中的長字串）
  4. 點擊「部署」→「新增部署作業」→ 類型選「網路應用程式」
  5. 執行身分選「我」，存取權限選「所有人」，按下「部署」
  6. 複製取得的 Web App 網址，貼到上方欄位

💬 LINE Bot 設定

  1. 前往 LINE Developers 建立 Provider 及 Messaging API Channel
  2. 在 Channel 設定中取得「Channel Access Token」（長期）
  3. 將 Token 貼到 Code.gs 的 LINE_CHANNEL_ACCESS_TOKEN
  4. 在 LINE 後台「Messaging API」→ 填入 Webhook URL（你的 GAS 網址）
  5. 開啟「Use webhook」並關閉「Auto-reply messages」
  6. 重新部署 GAS（版本選「新版本」）
